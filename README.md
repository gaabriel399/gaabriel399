> **Perché ho creato questo progetto?**  
> Lavorando costantemente con assistenti di codice basati su modelli linguistici, ho affrontato direttamente i loro limiti: allucinazioni sulle policy, credenziali esposte in chiaro e codice con sintassi malformata.  
> Ho progettato questo framework per costringere qualsiasi editor e agente AI (**Codex, Cursor, Windsurf, Claude Code, Antigravity**) ad auto-correggersi deterministicamente prima di consegnare il codice.

* ⚙️ **Focus:** Architettura Reflection (Attore-Critico), Validazione AST, Sicurezza delle credenziali
* 🧪 **Affidabilità:** Suite di test automatizzati Evals con Pytest
* 🔗 **Repository:** [gaabriel399/self-correcting-llm-guard](https://github.com/gaabriel399/self-correcting-llm-guard)
